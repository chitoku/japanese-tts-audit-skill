2026-10-21の実音声による一往復です。[聴き比べページ](index.html) をブラウザーで開いてください。

- 元音声：歴史語彙H0005、H0007、H0009。S001/S003の承認は既存のユーザー聴取記録を引き継ぎ、H0007の「脇本陣→ワキモトジン」を修正対象にしました。
- 元の台本を維持し、生成用入力だけ「わきほんじん」に変更。エージェントが既存のVOICEVOX APIでS002だけを1回再生成しました。内蔵のElevenLabs生成は使用していません。

```sh

```

[project.json](project/project.json) に各文の版・生成用入力・提供元・音声ハッシュ・採用根拠があり、[verification.json](verification.json) が保持の検証記録です。修正前の結合は既知の誤読を含むプレビュー、修正後はASR根拠で承認した版を含みます。聴取済みの正解音声として配布するものではありません。

この修正版はベンチマークの [inbox](../../data/benchmark/inbox/voicevox-history-repair-H0007.json) に、人の再聴取待ちとして登録しています。固定済みv0.1.0のラベルや採点件数は変更していません。音声の利用条件は [第三者部品の注意](../../THIRD_PARTY_NOTICES.md) を参照してください。
