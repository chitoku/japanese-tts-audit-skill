# タイムライン検聴（試作）

制作者が「疑わしい箇所を聴く → 判定 → 必要な文だけ修正する」ための画面です。従来のカード一覧も利用できます。

## 開き方

```sh
tts-audit serve outputs/check --open
```

`--open` はタイムラインを開きます。別途開く場合はサーバーが返す `timeline_url` を使います。従来のレポートからもリンクできます。サーバーの保存先とリビジョン競合防止は共通です。新たな音声生成や有料APIへの送信はしません。

## 画面

- 上ペイン：確認カードと判定。右約20%に確認キュー。詳しいメモは任意。
- 下ペイン上段：固定120px/秒の拡大表示。波形の上に元の台本、下にカナ起こし。再生位置を中央に表示。
- 下ペイン下段：全体波形、認識区間タイル、候補の位置目安、拡大表示の枠。＋／−でズームし、枠を左右にドラッグして拡大表示を移動。
- キュー：位置目安と残り件数。機械の指摘の種類と、人の判定を別に保持。

波形は実際の `audio.wav` をブラウザー内でデコードして作ります。認識区間タイルはサムネイルではなくカナ起こしのテキストです。動画入力・実動画サムネイルは未実装です。

**通常のローカルASRでは、音声から推定したトークン時刻を使います。** 台本の辞書読みとカナASRを照合し、その対応とトークン時刻から台本・カナ・候補を配置します。複数文字のトークン内は按分します。時刻を取得できない場合のみ認識区間内の等間隔配置に戻ります。いずれも人が確定した単語境界ではありません。元のASRや台本、機械検出の範囲は変更せず、表示用の位置目安を別に作ります。「ニ」のような短い差は全体の最初の一致を使わず、対応する文脈の近くで位置を決めます。

すべての検出候補を両文字段に黄系で強調し、選択中は紫にします。色付きの語からカードを選べます。候補を選ぶと位置目安の少し前へ移動し、「この指摘を再生」は前後の文脈を含めて再生します。照合品質が低いと対応も誤る可能性があるため、目安がずれていれば周囲も聴いてください。

### ドラッグと描画

文字DOMは読み込み時に一度作り、移動は親のtransformで行います。拡大波形は1024pxのタイルをキャッシュし、表示範囲の近くを用意します。全体波形はサイズ変更・ズーム・確認範囲の追加時だけ再描画します。ポインター入力はrequestAnimationFrameでまとめます。

ドラッグ中は再生を一時停止して表示のみ更新し、指を離した時に音声を一度シークします。ドラッグ前に再生していた場合は再開します。タイムラインを動かしても、選択カードや判定は勝手に切り替えません。

## 操作

| 操作 | キー |
|---|---|
| 再生・停止 | Space |
| 1秒戻る・進む | ← / → |
| 前の指摘／次の未確認 | ↑ / ↓ |
| 次の指摘（判定済みも含む） | Shift＋↓ |
| 自動追従の切り替え | F |
| 問題なし／修正が必要／保留 | 1 / 2 / 3 |
| 台本・ASRの文字を選択して手動指摘 | M |
| 直前の判定を取り消す | ⌘Z / Ctrl+Z |

入力欄では通常の入力を優先します。判定後に自動で次へ飛ばさず、補足入力や再聴取を続けられます。

「全体を聴く」で候補の選択を外してスキャンできます。機械の見逃しはMで追加してください。印のない範囲は正読保証ではありません。「この表示範囲を聴取確認済みにする」は明示操作で範囲を記録し、候補の判定とは分けます。再生しただけでは確認済みになりません。

## 保存と互換性

`review-state.json` を正本に、既存の `notes` と追加の `annotations` を保存します。

- `manual_flag`: `M-` のID、開始・終了秒、作成時刻。判定は同じIDの `notes`。
- `reviewed_range`: `S-` のID、人が確認済みと指定した範囲。候補数・判定数には含めません。
- `machine_candidate_count` と `manual_candidate_count` を区別し、`candidate_count` は合計。

元の `report.json`・ASR・音声は変更しません。旧画面が `annotations` を送らなくても追加記録を保持します。未知の候補への判定・範囲外・不正な時刻・同じ追加IDの内容変更は拒否します。JSON書き出し／取り込みも追加記録を保持します。別タブの古い更新は409で拒否し、上書きしません。

手動フラグや確認範囲の削除・範囲調整は未実装です。「取り消す」は判定の取り消しです。ブラウザーの下書きをサーバーへ自動マージせず、サーバーを優先します。保存失敗時は画面を閉じず、JSONで退避してください。

## 再生に合わせた自動追従と判定色

「自動追従 ON」ではSpaceで再生を続け、1〜3で現在のカードを判定できます。位置目安の約0.2秒前に次のカードへ切り替わり、次の候補までは現在のカードを保持します。判定の有無で再生速度や位置を変えず、判定し損ねた候補は未確認のまま残します。判定済みの候補も、音声を戻して再生すれば追従対象になります。

音声時刻のある新しいページの初期設定はON、概算位置のページはOFFで、切り替えはブラウザーに記憶します。手動でカードを選択・前後移動・ドラッグ・リプレイ・Mで追加・全体スキャンするとOFFへ戻り、その操作を優先します。メモ欄の入力中はカードの自動切替を一時停止します。候補が密集している／位置目安がずれている場合はSpaceで停止、速度0.8倍、または手動の↓で確認してください。正確な単語時刻を保証する追従ではありません。

未確認は黄系、「修正が必要」は赤、「問題なし」は緑系、保留は落ち着いた黄系です。台本・カナ・全体バー・確認キューに判定を反映します。選択中は紫の枠を重ねるため、赤の判定色を失いません。判定前からボタンのチェックは緑、バツは赤、保留記号は黄系で表示します。選択後はボタンの背景・枠、カードの枠、該当語を同じ判定色にそろえます。状態は色だけでなくカードやキューの文字・記号でも表示します。

### 確認キューの選択とスクロール

判定ボタンの `aria-pressed` と、キューで現在のカードを示す `aria-current` は別に管理します。判定処理がキューやタイムラインの `data-verdict` を持つ要素へ適用されないよう、操作対象を判定ボタンに限定しています。

キューは行を再利用し、選択中は常に1行です。自動追従でカードが変わると、その行をキュー中央付近へ移動します（上下端では可能な範囲まで）。手動で前後のカードに進んだ場合も選択行を表示範囲に入れます。モバイルの横並びキューは横方向に追従します。外側のページ全体はスクロールしません。

「未確認」フィルターでも現在のカードだけは判定後も残し、「現在のカード」と明示します。次へ進むと判定済みの旧カードは一覧から外れます。残り件数は実際の未確認数で、表示のために残したカードは含みません。候補は機械の粗い区間開始時刻ではなく、タイムラインと同じ位置目安の順に並べます。

## 音声から推定した表示時刻（試験導入）

レポートと同じディレクトリに `audio-timing.json` がある場合、Kana Whisperのトークン時刻（cross-attention＋DTW）を、既存の認識文字に対応づけた位置を使います。台本・カナ文字・候補マーカー・自動追従が同じ時刻を参照します。元の認識文、機械の検出結果、音声、聴取判定を書き換えるものではありません。

時刻データは実行ID・音声ハッシュ・元の認識文ハッシュ・文字列・時刻の範囲と順序を検証します。不一致なら従来の位置目安に戻します。追加の認識で文字が変わった部分には時刻を直接移さず、前後の一致箇所から補間します。一つのトークンに複数のカナが含まれる場合も内部は按分です。人が確定した単語境界ではなく、常に正確な同期を保証しません。

2026-10-22の63.39秒のv2音声で試行しました。節約の範囲は従来44.59〜45.30秒から45.76〜46.30秒へ、相殺は45.72〜46.43秒から46.78〜47.18秒へ移動しました。認識文を保存し直さず別ファイルとして追加し、既存の判定を保持しています。通常の `tts-audit check` でも、ローカルASRの最初の認識と同時に時刻を取得して保存します。`--no-timestamps` で省略できます。取得失敗時も検査を継続し、概算位置を表示します。`tts-audit serve DIRECTORY --open` でタイムラインを開けます。音声時刻のある新規ページは自動追従ONで開始し、保存済みのユーザー設定を優先します。

## 対象ファイルと自動保存先

ヘッダーの「対象・保存先」で、元の音声・台本パス、確認用音声、判定JSONの絶対パス、実行ごとのセッションID、作成日時、保存リビジョンを確認できます。通常のCLIは `source_files` に元パスを記録します。古いレポートにない元パスは推測せず「未記録」と表示します。

セッションIDには既存の `run_id` を使います。パスだけからIDを作ると同じファイル名を差し替えた際に混ざるため、実行ごとのIDと音声・台本・レポートのハッシュで区別します。サーバーが返す保存完了後はエージェントが `review-state.json` を直接読めます。「JSONバックアップ」は任意の控えで、通常はダウンロード・添付不要です。サーバーなしの場合はブラウザー保存と明示し、書き出しが必要です。

## 手動の指摘を編集・削除する

M／「文字選択して手動指摘」は、台本かASRの文字を選択して追加します。自動検出・手動指摘とも共通の編集欄に、台本の表記と参照読み、機械のASR、人が聞こえた読み、補足メモを表示します。機械の結果は読み取り専用で、人の記録と区別します。手動の台本表記・期待読みは編集できます。入力欄のラベルは左に配置し、左右／上下のレイアウトを切り替えられます。

「この手動指摘を削除」でキュー・タイムライン・残り件数から外し、「取り消す」で復元できます。追加直後の「取り消す」でも取り下げられます。保存では元の注釈を残して判定メモに `deleted: true` を記録するため、後から古いJSONを取り込んでも注釈の欠落だけで削除が復活しません。対象語は `target_text`、期待読みは `expected_reading`、実際の読みとメモは従来の `heard`／`note` に保持します。エージェントは削除済みを修正対象から除いてください。

## キーボードと再生範囲

FはFollow（自動追従ON/OFF）、Mは文字選択モード、Rは現在のカードに対応する音声を前後の余白付きで聴き直す操作です。Rの対象は確認キュー・タイムラインで選んだカードで、ドラッグによる範囲選択ではありません。1／2／3は従来どおりの判定、↓は次の未確認、↑は前の指摘、Shift＋↓は判定済みも含む次の指摘です。Aはカード選択を外した全体確認、＋／−／0は全体タイムラインの拡大・縮小・全体表示。⌘Z／Ctrl＋Zは直前の操作の取り消しです。?か「キー一覧」で一覧を開けます。入力欄ではこれらのショートカットを発火させません。

手動指摘は対象語が未入力でも、拡大タイムラインの波形上に破線の範囲と「⚑ 手動の指摘」を表示します。ラベルをクリックするとカードを選べます。台本の語を特定できた場合の文字ハイライトとは別の表示です。判定色・選択枠・削除・取り消し・再読み込みに追従します。

## 表示テーマ

ヘッダーの「テーマ」でLight／Dark／Autoを選べます。既定はAutoで、OS設定の変更にも追従します。明示的に選んだLight／DarkはOSより優先します。選択はブラウザーの同じ提供元のストレージに保存し、同じ提供元の別タブにも反映します。ストレージが使えなくても、そのページでは切り替えられます。配色の変更で波形タイルを描き直しますが、再認識・再生成や判定の保存更新は行いません。

## 文字を選んで手動指摘

Mまたは「文字選択して手動指摘」で再生を一時停止します。台本・ASRをなぞって離すと、追加ボタンを経由せずカードを作り、判定を「修正が必要」にして `heard` へフォーカスします。ASRから選ぶと `heard` に選択文字を入れます。最初に押した文字全体を含め、ハイライトと保存する文字範囲を一致させます。誤って追加した場合は削除・取り消し、判断がつかない場合は保留へ変更できます。既存の時刻だけの手動指摘も読み込めますが、新規追加は文字選択に一本化しました。

`notes[M-ID].text_selection` は `source: script | asr`、UTF-16の `start`／`end`（末尾を含まない）、`text` を保持します。保存時に元の台本／元のASRとの一致を検証し、ASRや機械の検出結果は変更しません。ASR文字選択は原文側の箇所を人が確定したことを意味しません。対象語を手入力で変更すると文字の固定範囲を解除し、通常の対象語による近傍推定に戻ります。削除・取り消しは従来の手動指摘と共通です。

選択待ちは台本・ASRに30pxごとの虹色の濃淡を表示し、文字をなぞる間は選択範囲だけの滑らかな虹色へ切り替えます。ボタン内に案内を出し、追加行を挿入しないためタイムラインは移動しません。Esc・M・ボタンの再クリックで解除します。`prefers-reduced-motion` では背景を静止させます。

確認キューの手動指摘は右クリック（キーボードでは項目にフォーカスしてShift＋F10）で操作メニューを開けます。項目名と時刻を確かめ、「この手動指摘を削除」を選びます。現在のカードとは別の項目を削除しても、カードの選択は維持します。削除は「取り消し」で戻せます。Escまたは外側のクリックで閉じ、機械検出の項目にはこの削除メニューを出しません。


## キューの絞り込みと入力後の操作

「すべて／未確認／要修正」にそれぞれ現在の件数を表示します。要修正は `verdict: error` の自動検出・手動指摘を表示し、保留や参照読みの確認は含めません。絞り込み切替時に選択が条件外なら最初の該当カードを選び、該当なしならカード選択を外します。判定変更や自動追従で条件外になった現在カードは、編集中に消えないよう残し、条件外と明記します。元の判定データは変更しません。

補足メモの通常のTabはタイムラインへフォーカスを戻し、続けてSpaceで再生・停止できます。Enterは改行、Shift＋Tabは通常の逆方向移動です。IME変換中はこの操作を横取りしません。各ショートカットは対応するボタンに約650msのグローを表示します。1／2／3は判定色に合わせ、入力中はショートカットを無効にします。動きを減らす設定では輪郭の点灯だけにします。
