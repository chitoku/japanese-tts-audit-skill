# 2026-10-21 時点のプロジェクトの位置

目的は、制作者がAgentに「台本＋生成音声」を渡すと、疑わしい箇所を音声付きで確認し、必要な修正を既存の制作環境へつなげられるCLI＋Skillを作ること。独自のTTSリーダーボードは作らない。読みの違いの原因がDeep Learningに特有である、という因果判断もこの実験では行わない。

## 現在地

Privateのv0.2.0-beta。台本・音声の点検、音声付きHTML/JSON、ローカルサーバーへの判定保存、AgentがJSONを読む流れ、一文だけの再生成・差し替えによって他の確認済み音声を保持する制作実演まである。点検は生成元のサービスを問わない。CLI内蔵の生成アダプターはElevenLabs向けで、他サービスの修正はAgentが既存環境につなぐ。

今日の大規模調査は製品を検証する材料集め。これ自体が製品の目的ではない。次は追加生成よりも、調査で露呈した参照読みと判定UIの問題を製品へ戻す段階。

## 今日分かったこと

1. **ASRが正しく認識しても参照が誤ると見逃す。** 「米」をSudachiがベイと解析し、TTS・ASRもベーとなる例は差分なしになった。穀物を指す3文の参照をこめに訂正。H0165のベーとH0169のレーが対象語外の候補に現れ、H0003の正しいコメは差分が消えた。音声やASRは再生成していない。
2. **辞書に載る読みを意味抜きに全部許容してはいけない。** 人足の労働者・運搬人の意味はにんそく。ひとあしの別語義と混ぜたためH0015/H0016を見逃していた。実験用レポートでは修正した。
3. **同義の別読みは理由付きで表示する。** 鋳物師はいもじ／いものしが同義。鍛冶のタンヤも辞書にある。単に初期参照だけを表示して差分なしとすると、利用者には照合の根拠が伝わらない。実験ページは許容した読み・理由・根拠リンクを常時表示する。
4. **対象語の正しさと全文の正しさが混同される。** 刺股が正常でも同じ文の捕り物→トリブツが誤る。「違いなし」ボタンと誤読を指摘したメモが同居する記録は、メモを捨てず補足記録へ取り出した。石高の文の米→ベーも同様。判定の勝手な書き換えはしていない。
5. **語数・文数・音声数を分ける必要がある。** 同じ語は1文の設定で100語を確認しても200音声を確認したことにはならない。別文脈へ判定をコピーしない。
6. **「だんこん・せんぞう系」の中心例は多くない。** Googleの自然薯→ジテンショは人の聴取メモがある。鱈→だら、VOICEVOXの遵守→じゅんし・飛脚→キキャクなどの音の変化は別分類で残す。発音の曖昧さ、ASRの誤認、既存音訓の選択違い、語の脱落を一括して同じ種類の誤読にしない。

Google比較のボタン記録はG: 正常62・違い18・参照見直し11・保留10、V: 正常73・違い11・参照見直し7・保留10（各101文、未判定の明示記録は別に1文ずつ）。これらをそのままモデルの優劣やエラー率として公表しない。探索用データ、同一話者、選別聴取、参照の不備という制限がある。

## 次の区切り

1. 追加生成をいったん止め、今日の聴取を項目単位で整理する。特にH0075、H0107、H0165のボタン・実際に聞こえた読み・メモの関係を明示する。別文脈100本の聴取を自動的に追加ノルマにしない。
2. 人足・米の見逃し、鋳物師の許容、捕り物の対象語外誤読を保存済みASRによる小さな回帰セットにする。汎用CLIで参照の根拠、参照の不確実さ、許容した別読みを利用者に示す。実験固有の単語修正を汎用の文脈理解実装と呼ばない。
3. その修正を、短い制作フローに通して再検証する。正常音声へ不要な修正を求めないことと、実際の問題を既存サービスで文単位修正できることを確認し、公開用の完成例と記事へ戻る。

新しいモデルの大量比較・語彙の再拡大・独自リーダーボードは、この区切りには含めない。一般公開、タグ、GitHub Releaseは未実施。今日はPrivateへのコード・証拠・残課題の保存で終了できる。

## 誤読実例の継続管理を追加

調査結果のスナップショットだけでは再利用できる正本になっていなかったため、[data/benchmark](../data/benchmark/README.md) に初版v0.1.0を固定しました。語・文脈・期待読み・聴取読み・出典・音声ハッシュを観測IDで結び付け、聴取済み誤読32箇所（23語）と誤警報対照9箇所を開発用の採点対象にしています。収集報告39件、要裁定15件、別読み等30件は別状態で保持し、採点から外します。

旧2,000文を含む1,150表記・2,241例文は候補プールとして登録しました。すべてで誤読を確認した、あるいは読みの正解を再検証した、という意味ではありません。71音声をRepo内に同梱し、収集元のMacがなくても検出用入力の書き出し・ハッシュ検証・箇所単位の採点が可能です。モデルを新しく実行した評価成績はまだ出していません。独自リーダーボードの再開ではありません。


## 既存制作環境との接続を実装に反映

文単位プロジェクトは既定でサービス非依存になりました。初期化・取り込み・点検・承認・採用版の選択・結合はCLIが担当し、生成・該当文の再生成はAgentが制作者の既存サービスで行います。取り込み時に生成用の修正テキストとモデル・声・設定の情報を記録でき、他の承認済み音声を保持します。ElevenLabsの内蔵生成は任意アダプターとして残しています。READMEとSkillの主経路も同じ流れに更新しました。
